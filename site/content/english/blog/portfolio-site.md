## 개요

- **기간**: 2026-11-04 ~ 2026-11-07
- **상태**: 완료
- **구분**: 2026학년도 초급프로젝트 과제, **개인 수행**

## 목적

테마 데모에 남아 있던 가상 인물과 데모 문구를 내 정보로 바꾸고, 코드를 push하면 자동으로 배포되는
사이트를 만들어 누구든 로그인 없이 볼 수 있게 하는 것이 목표였습니다.

## 내 역할

혼자 수행한 개인 활동입니다. 테마 설정, 페이지 작성, 배포 설정, 동작 점검을 직접 했습니다.
설정 변경 자동화와 오류 분석에는 AI(Claude)의 도움을 받았고, 결과는 직접 실행해 확인하였습니다.

## 수행 과정

1. Hugoplate ZIP을 받아 수업 제공 스크립트로 GitHub Pages 배포 구조 준비
2. 사이트 주소·이름·메뉴·한국어 설정을 적용하고 데모 기능(후기·쿠키 팝업 등) 끄기
3. 소개·활동 페이지 작성, 데모 이미지를 내 이미지로 교체
4. main 브랜치에 push해 GitHub Actions로 자동 배포
5. 배포 후 본문이 비어 보이는 문제를 찾아 콘텐츠 폴더 설정(contentDir)을 바로잡고 다시 확인

**Hugoplate를 고른 이유**: 반응형과 다크모드가 기본으로 들어 있고, Tailwind CSS와 Hugo 모듈을 쓰는
구조를 직접 다뤄 보며 요즘 웹 개발 도구가 어떻게 이어지는지 익히고 싶었기 때문입니다.

  나오지 않는다는 것을 직접 겪고, 화면의 문구를 검색해 원본 파일을 찾는 방법을 익혔습니다.
